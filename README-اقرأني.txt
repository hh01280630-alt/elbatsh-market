موقع البطش ماركت — طريقة التشغيل

محتويات الفولدر:
  index.html      الموقع (ماتعدلش فيه)
  products.json   المنتجات والأسعار والكميات (بيتولّد من البرنامج بزرار 🌐 نشر للموقع)
  shop.json       إعدادات المحل (رقم الواتساب، التوصيل، أقل طلب، المواعيد) وبتعدّلها بإيدك
  logo.png        اللوجو
  images/         صور المنتجات (اسم الصورة = كود المنتج)

1) الرفع (مجاني): افتح app.netlify.com/drop واسحب الفولدر كله عليه. هيديك رابط تبعته للزباين.
   مهم: الموقع ما بيشتغلش لو فتحت index.html بالضغط عليه من الجهاز، لازم من الرابط المنشور.

2) إعدادات المحل: افتح shop.json وعدّل:
   whatsapp = رقم واتساب المحل دولي بدون + (مثال 201060124814)
   deliveryFee = رسوم التوصيل (0 لو مفيش)
   minOrder = أقل طلب (0 لو مفيش)
   delivery = false لو استلام من المحل بس
   hours = مواعيد العمل (نص حر)

3) الصور: حط الصورة في فولدر images باسم الباركود، مثال 6224001608254.jpg (أو png/webp).
   المنتج اللي ملوش باركود: اسم الصورة = كود الميزان. أعد الرفع بعد الإضافة.

4) تحديث الأسعار والكميات: من برنامج الكاشير > المخزون اضغط 🌐 نشر للموقع، هيحفظ ملف products.json.
   في GitHub: افتح الـrepo > Add file > Upload files > اسحب products.json الجديد > Commit changes.
   الكمية 0 أو أقل = بيظهر "نفد". الأكتر مبيعًا بيظهر الأول جوه كل قسم.
   قبل أول مرة: صفّر المخزون السالب من أداة المبرمج عشان ماتظهرش أصناف متاحة "نفد".

--- إعدادات الصفحة في shop.json ---
announcement : الشريط الأسود اللي فوق (سيبه "" لو مش عايزه)
facebook     : حط رابط صفحة الفيس (مثال https://www.facebook.com/اسم-الصفحة) وهيظهر زرار الفيس تحت
branches     : الفروع (الاسم والعنوان والتليفونات)
banners      : الإعلانات المتحركة فوق. كل إعلان: title, text, icon, bg, bg2 (ألوان)
               وممكن تضيف image: "images/banner1.jpg" لصورة إعلان بدل الأيقونة
               وزرار الإعلان: search (يبحث عن كلمة) أو cat (يفتح قسم) أو url (رابط) أو goto:"branches"
الشكاوي والمقترحات بتوصل على واتساب المحل.
